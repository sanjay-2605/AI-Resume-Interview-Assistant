# AI Resume & Interview Assistant

An AI-powered full-stack web application that helps users improve resumes, generate interview questions, and evaluate interview answers using OpenAI APIs.

## Features

- AI Resume Feedback
- Interview Question Generation
- AI-Based Answer Evaluation
- Responsive React Frontend
- Node.js + Express Backend
- OpenAI API Integration

## Tech Stack

Frontend:
- React.js
- JavaScript
- Axios

Backend:
- Node.js
- Express.js
- OpenAI API

Database/Auth:
- Firebase
